# Changelog

Inrun follows [Semantic Versioning](https://semver.org/). Until `v1.0`, minor versions may contain breaking changes.

## v0.1.0

Orkestra becomes Inrun, and versions start again at `v0.1.0`.

Everything Orkestra named is renamed: the CLI is `inrun`, the API group, labels, annotations and finalizers are `inrun.dev`, and Katalog, Komposer and Motif are Blueprint, Stack and Module. Resources created by Orkestra are not adopted.

Orkestra's history is on the `archive` branch and the `orkestra-v0.7.18` tag.
